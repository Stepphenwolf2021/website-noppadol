# Veritas source snapshot

2026-10-23, source https://www.veritastools.ca/en-ca (official Canadian site).

All 601 English-Canadian product sitemap pages were read as public HTML. The source's embedded `product.items` provides 1,194 distinct item IDs/SKUs; 3 further pages have no item records and remain explicitly labelled family references with unknown SKU and price. The 1,197 references include accessories and other/unspecified brands present on the site; the source website does not imply every item is manufactured by Veritas.

Identifiers preserve the source item ID under `urn:noppadol:catalog:veritas:`. Family-only identifiers use `P` followed by the source page ID. No cross-provider name or SKU matching is performed.

Attributes are item-specific option values. Prices are Canadian-dollar snapshots of source item offer 1, quantity 1; no volume/dealer offers, shipping dimensions or stock inferred from publication status. Missing values remain null. Images are remote source URL references, without image-file redistribution or a claim of license. Source URLs and page SHA256 identify evidence. `veritas.json`, `veritas.jsonld` and the combined SQLite retain the same model data; source-specific earlier provider datasets remain intact.

This is reference model data, not an inventory, ownership assertion or valuation of a personal item. A local selection is created only by the user's explicit action.
