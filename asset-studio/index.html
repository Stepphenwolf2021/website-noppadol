สำรวจความเชื่อมโยง

สีเขียวคือทะเบียน สีส้มคือไอเดีย สีม่วงคือ Mission

เส้นประคือแรงบันดาลใจที่เสนอไว้ ไม่ใช่ข้อเท็จจริงที่ยืนยันแล้ว

บันทึกให้น้อย แต่ใช้ประโยชน์ได้มาก

  1. เลือกรายการให้ถูกระดับ กบที่อยู่กับคุณเป็น “ทรัพย์สินรายชิ้น” ส่วนข้อมูลร่วมของรุ่นเป็น “รุ่นผลิตภัณฑ์” แผ่นเสียงแยกชิ้นที่ถือครองออกจากฉบับเผยแพร่
  2. เลือกคำศัพท์ที่มีนิยาม ค้นได้ทั้งคำหลักและคำเรียกอื่น เลือกเฉพาะคำที่ตรงบริบท ระบบไม่ถือว่าคำคล้ายกันเป็นสิ่งเดียวกัน
  3. เพิ่มเฉพาะรายละเอียดที่มีประโยชน์ เลือกฟิลด์จาก Metadata Standard อ่านคำแนะนำระดับข้อมูล ใช้หน่วยกับค่าตัวเลข และระบุวิธีได้ข้อมูลทุกค่า
  4. เก็บบันทึกต้นทาง เขียนข้อสังเกตหรือข้อความอ้างอิงให้ครอบคลุมข้อมูลที่กรอก พร้อม URL ถ้ามี ระบบเก็บสำเนาข้อความและรหัสตรวจสอบในกราฟ
  5. สร้างไอเดียที่มี Mission เลือกทรัพย์สินที่เกี่ยวข้อง ระบุเหตุผลและข้อจำกัด พร้อมบันทึกที่ทำให้เกิดไอเดีย
  6. สำรองและส่งออก ไฟล์สำรองใช้กลับมาแก้ไขได้ ส่วน JSON-LD เป็นกราฟพร้อมนำไปตรวจ SHACL และใช้ต่อกับระบบความรู้

ทุกข้อมูลเป็น owner / draft / unreviewed รุ่นนี้ยังไม่รองรับบัญชีสมาชิก การซิงก์หลายเครื่อง กองทุน/crypto และการเสนอไอเดียอัตโนมัติ

ข้อมูลซ้อน เช่น credits และรายการบริษัท เก็บเป็นข้อความ JSON ที่รักษาบทบาทและขอบเขตเดิมได้ แต่ยังไม่แตกทุกส่วนเป็นโหนดอัตโนมัติ
